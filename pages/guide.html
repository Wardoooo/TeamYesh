HOW TO LOAD THE DEMO

  1. Chrome → Extensions → Developer mode → Load unpacked → this folder.
  2. Click the extension icon. It opens the store. Click the WiFi machine.
  3. Drag a peso from the tarpaulin into the slot. ₱1 is 60 seconds, ₱5 is 3 minutes, ₱10 is 5 minutes. The total picks the rate, so five ₱1 coins are 3 minutes and ten are 5 minutes. The code blinks on the LED.
  4. Type the 6 blinking characters. A correct code opens Google.
  5. The first half of the time is the ads phase. Then CAPTCHA, then browsing.
  6. On a real page, click the bamboo timer for the session tools. There is no GOD MODE button on the browser.
  7. Skip caps at 3. Catching the fleeing X expires the session. CAPTCHA caps at 4. Disconnects cap at 2. The terms button settles after 2 moves.
  8. The certificate page replaces the tab. When time hits 0 it expires, any star rating becomes 5, then the report.
